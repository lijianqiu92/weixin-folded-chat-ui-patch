# 固定版安装与恢复

先构建，再进入 `dist/fixed-patch/`；保留目录中的所有文件，特别是 `Weixin.original.dll`。

1. 确认可以完全退出微信。若本机聊天记录不保留，先等消息测试，暂缓安装。
2. 双击 `Install-FixedPatch.cmd`，允许管理员权限。
3. 完全退出微信，包括托盘中的微信。安装器会等待，不会强制结束微信。
4. 按提示继续，成功后重新打开微信，检查显示和入口操作。
5. 再完整退出并重开一次，验证无需手动启动补丁仍生效。

安装器先校验原文件、补丁和备份的 SHA-256，等待进程退出后再次校验，再以同卷文件替换方式安装。默认目标为 `C:\Program Files\Tencent\Weixin\4.2.0.13\Weixin.dll`；自定义安装位置请调整安装脚本中的 `$target` 后再运行。

如果无法启动微信，运行 `Restore-Original.cmd`，恢复后重新打开微信。恢复器只接受本补丁生成的精确文件，遇到微信更新或其他修改会停止，避免覆盖新版本。

重装微信并覆盖该 DLL 后补丁消失。它没有自动重装、自动注入或更新适配功能。退出当前进程才能清除已加载的内存修改。

修改后的 DLL 没有腾讯原版的有效数字签名。程序自身的完整性验证可能拒绝加载。本项目不改变任何系统签名或安全设置。

固定版目前仅完成离线结构、校验和与重定位验证；实际重启测试待完成。请保留原版备份。
