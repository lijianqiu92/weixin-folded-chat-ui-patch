# 实现说明

本机二进制包含 `Qt 5.15.14 ... static release build; by MM`。主要 UI 代码静态编译在 Weixin.dll 中，而不是独立 Qt DLL 或外置 QSS。

仅当祖先是 `mmui::ChatSessionCell`，当前对象严格等于对应字段，且视图模型的会话标识完整匹配 `@placeholder_foldgroup`，才修改显示：

| 对象 | 字段偏移 | 行为 |
|---|---:|---|
| 摘要 | +0x290 | 跳过绘制 |
| 未读提示 | +0x298 | 跳过绘制 |
| 图标 | +0x260 | 绘制前通过 Qt 隐藏摘要容器，让已有布局居中标题；图标本身照常绘制 |

会话单元主虚表 RVA 为 0x9c8c5c8，模型字段 +0x2f0，会话标识是模型 +0x160 的 std::string。公共绘制入口 RVA 为 0x1e8d3f0。原 12 字节：`41 56 56 57 53 48 83 ec 48 48 89 ce`。这些地址只适用于 README 所列精确 SHA-256。

补丁保留入口及命中区域，不改消息模型和未读数量。每次重新识别会话类型，记录被补丁隐藏的容器，以便禁用或复用成普通聊天时恢复。其恢复记录为单个容器，当前只验证了一个主窗口中的折叠入口；多窗口/多个入口情形尚未验证。

手动模式：分配独立的数据页与只读可执行代码页，短暂停止线程，检查没有线程位于覆盖区，再安装跳转；异常时恢复原始指令并恢复进程运行。关闭过滤只改开关，执行中跳转保留到进程退出。

固定模式：增加 `.wxui`（读/执行）与 `.wxdata`（读/写），复制并扩展重定位表，修正映像大小与校验和。绝对地址操作数与原入口跳转都加入重定位。移除证书目录，防止误称修改文件仍具原版有效签名。

Qt 调用位于微信原有绘制线程，保存易失寄存器及 XMM0–5，满足 x64 调用栈对齐。新增代码没有完整的 Windows 异常展开元数据，不适合在内部调用异常或复杂调试展开情况下使用；当前没有这些场景的验收结果。

本仓库不包含微信二进制、反汇编全文、进程内存转储或个人界面截图。
