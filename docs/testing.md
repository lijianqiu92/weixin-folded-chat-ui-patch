# 测试状态

## 已完成

- Windows 微信 4.2.0.13 原 DLL 哈希、x64 架构与关键原始指令校验。
- 本机内存版：用户确认红点隐藏、消息预览隐藏、标题上下居中。
- 13 组机器指令模拟与调用栈检查。
- 固定版：PE 校验和、附加节、扩展重定位表、模拟不同加载基址后的指令一致性。
- 本机固定副本可作为不执行代码的 Windows 映像映射，未调用 DLL 初始化。

- 普通聊天的预览、红点与其他提示不受影响。
- 控件复用、滚动、缩放、窗口调整与主题切换。

固定版重启测试会退出微信。聊天记录不保留的设备请先做好自己的数据安排，项目不会代替你退出或重登。
